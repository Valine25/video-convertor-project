# 🎬 PulseForge AI Reel Generator

PulseForge AI Reel Generator is an AI-powered short-form video generation platform that transforms long-form videos into viral-ready Instagram Reels, TikToks, and YouTube Shorts automatically.

Built using React, Node.js, MongoDB, Python AI pipelines, FFmpeg, and Groq LLM APIs.

---

# ✨ Features

## 🎥 AI Reel Generation

* Upload long-form videos
* AI automatically detects the best viral moments
* Generates cinematic short-form reels

---

## 📱 9:16 Platform Reel Generation

* Automatically converts reels into vertical format
* Optimized for:

  * Instagram Reels
  * TikTok
  * YouTube Shorts

---

## 🧠 AI Highlight Detection

Uses:

* Audio energy analysis
* Speech pacing
* Sentiment analysis
* Semantic scoring
* Story flow detection

to identify the most engaging moments.

---

## 🪄 AI Reel Captions

Generates:

* Viral reel hook captions
* Short-form social media style captions
* Gen Z / Instagram-style hooks

Example:

* “This fit is unreal 😭 Need this ASAP.”
* “Nah this transition is insane 🔥”

---

## 🏷️ Smart Hashtag Generation

AI-generated hashtags based on:

* Video context
* Transcript
* Reel content

---

## 🖼️ AI Thumbnail Generation

Automatically generates thumbnails using:

* Face detection
* Sharpness analysis
* Contrast scoring
* Brightness balancing
* Viral moment detection

---

## 📂 Upload History

* Stores generated videos
* Recent uploads section
* Reel preview support
* Delete functionality

# 🚀 Installation

## 1. Clone Repository

```bash
git clone https://github.com/your-username/pulseforge-ai-reel-generator.git
```

---

## 2. Frontend Setup

```bash
cd frontend
npm install
npm start
```

---

## 3. Backend Setup

```bash
cd backend
npm install
```

---

# ▶️ Run Backend

```bash
npm start
```

Backend runs on:

```text
http://localhost:5001
```
